# 数据来源与许可

本项目的代码以 [MIT](../LICENSE) 发布。它不打包、不再分发任何第三方题库或标注内容，只做两件事：

1. 在你登录自己的粉笔账号后，**只读**拉取你本人的练习数据；
2. 把第三方标注库「考公脑库」克隆到**你自己的磁盘**，并在本地生成索引。

因此，分享本仓库不等于分享题目、材料、图片或第三方标注。

## 一、考公脑库（kaogongzhentizhengliu）

- 出处：<https://github.com/ERRRC/kaogongzhentizhengliu>
- 形态：Obsidian vault，覆盖 2016–2026 年国考/省考/联考行测的「资料分析」与「判断推理」两个模块。
- 规模（本项目实测于该仓库 `84ab93d4`）：22,380 篇 Markdown，其中真题 11,282、考点 10,375、材料 717。
- 上游自有部分（考点分类体系、逐题标注「推理链 / 最快解法 / 易错点 / 母题抽象」、材料结构档案、
  考点 MOC、图谱配色与目录组织）：**CC BY-NC 4.0**，即「署名 - 非商业性使用 4.0 国际」。
  协议全文：<https://creativecommons.org/licenses/by-nc/4.0/legalcode.zh-hans>
  使用该部分需要**署名**（给出出处链接）且**不得用于商业目的**。

## 三、本项目对脑库做了什么

- `POST /api/naoku/import` 用 `git clone --depth 1 --filter=blob:none --sparse` 拉取副本，并设置
  sparse 规则 `/*` 与 `!/90-图片/`，**默认排除 `90-图片`**（21,829 张第三方配图，约 207MB）。
  已存在副本时只 `fetch --depth 1` 并重放到同一 sparse 规则，不递归删除任何目录。
- `POST /api/naoku/index`（或 `--naoku-import`）扫描该副本，在数据目录下写出 `脑库索引/`：
  真题/考点/材料的连接关系、地区年份、考点名，以及考点笔记「核心立场（母题抽象）」第一条 bullet
  截断到 300 字符的**短摘要**。
- 索引只用于本地检索与「按题号连到考点」；它不是 vault 的副本，也不含正文全文。
